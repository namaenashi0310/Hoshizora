###～日本語～

本体を空にかざすと、その方向の星空・星座線・太陽・月・惑星を表示します。
約 9100 個の恒星、88 星座の線と解説、星座の立体視、録画（AVI）に対応。

■ 必要なもの
- CFW（Luma3DS など）導入済みの 3DS（Old 3DS 向け。New 3DS は未確認）

■ 入れ方
- Universal-Updater: 設定 →「UniStore を選ぶ」→ 配布ページの QR コードを読む →「Hoshizora」を入れる（更新もここから）
  URL: https://github.com/namaenashi0310/Hoshizora/releases/latest/download/hoshizora.unistore
- star.cia: FBI などでインストール（ホームメニューから起動）
- star.3dsx: SD の /3ds/ に置き、Homebrew Launcher から起動

■ 初めて起動したとき
1. 言語を選ぶ
2. 地図で観測地を選ぶ
3. 太陽・月・北極星のどれかを中央の十字に合わせて A（白い線と緑の線を重ねると正確）
   3DS には方位磁石が無いので、これで方角を決めます。ずれてきたら A で何度でもやり直せます。

■ 操作
  A ............ 位置合わせ／決定
  B ............ キャンセル
  X ............ 表示の切り替え（上下2画面 ⇔ 上画面＋解説）
  Y ............ 星座線のオン/オフ
  スライドパッド上下 ... 拡大・縮小
  L ............ 録画の開始／停止（止めたあと A で AVI に書き出し）
  SELECT ....... 設定
  START ........ 終了
  3D ボリューム .. 星座が星の本当の距離に応じて立体に見えます

■ 注意
- 本体の時計は観測地の現地時間に合わせてください（時差・夏時間は自動計算）。ずれると星の位置もずれます。
- 録画は SD:/3ds/star/ に保存され、1 秒あたり約 17MB（最長 30 秒）使います。
- 任天堂とは関係のない非公式の自作ソフトです。使用は自己責任でお願いします。
- 無断での転載・改変・再配布はご遠慮ください。

■ クレジット
使用データ（Yale 輝星表、ヒッパルコス星表、d3-celestial、Natural Earth）とライブラリの出典・ライセンスは

###～English～

Point your 3DS at the sky to see the stars, constellation lines, Sun, Moon and planets in that direction.
About 9,100 stars, lines and descriptions for all 88 constellations, stereoscopic 3D and video recording (AVI).

■ Requirements
- A 3DS with custom firmware (e.g. Luma3DS) (made for the Old 3DS; not tested on the New 3DS)

■ Installation
- Universal-Updater: Settings -> Select UniStore -> scan the QR code on the download page -> install "Hoshizora" (updates too)
  URL: https://github.com/namaenashi0310/Hoshizora/releases/latest/download/hoshizora.unistore
- star.cia: install with FBI or similar (starts from the HOME Menu)
- star.3dsx: copy to /3ds/ on your SD card and start from the Homebrew Launcher

■ First start
1. Choose your language
2. Choose your observing site on the map
3. Center the Sun, the Moon or Polaris in the crosshair and press A (overlap the white and green lines for best results)
   The 3DS has no compass, so this sets the direction. If the view drifts, press A to align again.

■ Controls
  A ............ align / OK
  B ............ cancel
  X ............ switch view (two screens <-> top screen + description)
  Y ............ constellation lines on/off
  Circle Pad up/down ... zoom
  L ............ start/stop recording (press A afterwards to export an AVI)
  SELECT ....... Settings
  START ........ exit
  3D slider .... constellations appear in 3D according to the real distances of their stars

■ Notes
- Set the system clock to the local time of your site (time zone and DST are handled automatically). A wrong clock shifts the stars.
- Videos are saved to SD:/3ds/star/ and use about 17 MB per second (up to 30 s).
